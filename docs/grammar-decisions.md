# Решения по грамматическим вопросам (2026-10-19)

Заменяет `docs/grammar-open-questions.md`. Основной источник — консультации Ciberdúvidas da Língua Portuguesa (Iscte), для идиом — Dicionário Priberam, для реалий — официальные сайты и пресса Португалии.

Обозначения: **И** — решено по источнику; **С** — решено по собственному суждению (надёжного источника не нашлось или вопрос методический, такие пункты помечены ⚠). «Без изменений» — контент уже соответствовал источнику.

Принцип: норма — европейский стандарт уровня B1 (CAPLE); разговорный вариант, засвидетельствованный в Португалии, принимается как дополнительный правильный ответ.
