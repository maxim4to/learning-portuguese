# C · E2E: курс, практика, навигация — найденные баги

Поток C (Playwright, локальный режим). Формат: заголовок, шаги, ожидается, фактически, серьёзность P0–P3,
предполагаемое место, тест и артефакты. Тесты, воспроизводящие баг, помечены `test.fail(true, 'BUG C-NN …')`.
Скриншоты/трейсы появляются в `test-results/e2e-local/<тест>/` при снятии пометки `test.fail` (Playwright
сохраняет их только для упавших тестов).

### C-01 · Двойной клик по «Дальше» отвечает на следующее задание
- **Серьёзность:** P2 (medium) — засчитывается случайный ответ: портится результат урока, создаётся журнал ошибок / карточка.
- **Где:** src/features/exercises/ExerciseRunner.tsx:335 (onClick «Дальше» — защита только от клавиатурного дребезга, `e.detail === 0`);
  src/features/exercises/kinds/Choice.tsx:83 (вариант принимает клик сразу после монтирования).
- **Тест:** tests/e2e/local/course/runner-robustness.spec.ts › «double click on «Дальше» does not answer the next task [BUG C-01]» (все 3 проекта).
- **Шаги:** 1) `/topic/a1-presente-indicativo-regulares?tab=exercises`; 2) ответить на задания 1–7 (fill-gap);
  3) после ответа на 7-е сделать двойной клик по «Дальше» (следующее задание 8 — выбор варианта).
- **Ожидается:** открыто задание 8, ответа нет, варианты активны.
- **Фактически:** первый клик переходит к заданию 8, второй клик попадает в вариант, оказавшийся под курсором,
  — задание 8 сразу отвечено (часто неверно: «apanho — верный ответ», выбран другой вариант).
- **Заметки:** desktop-chromium, mobile-chromium, mobile-webkit; 100 %. Гипотеза: нужен такой же guard для
  мыши/тача (игнорировать клики по новому заданию ~250–300 мс после «Дальше» или `e.detail > 1`).

### C-02 · «Курс» никогда не предлагает «Подтянуть слабую тему», пока есть неначатые темы
- **Серьёзность:** P3 (low) — рекомендации «Курса» и «Сегодня» расходятся; ветка «Подтянуть слабую тему» фактически мёртвая.
- **Где:** src/features/syllabus/SyllabusPage.tsx:26 (`suggestTopics(progress, 1)`) + src/features/dashboard/stats.ts:125
  («Always leave room for one new topic»: при `count = 1` слабая тема вытесняется новой).
- **Тест:** tests/e2e/local/course/syllabus.spec.ts › ««Продолжить / Подтянуть» card suggests the weak topic like the dashboard does [BUG C-02]».
- **Шаги:** 1) засеять прогресс 30 % по `a1-ser-estar` (статус «Слабо»); 2) открыть «Сегодня» — главный шаг «Подтянуть: Ser и estar…»;
  3) открыть «Курс».
- **Ожидается:** карточка над списком — «Подтянуть слабую тему · Ser и estar…» (как на главной).
- **Фактически:** «Продолжить курс · Артикли, род и число…» (первая неначатая тема); слабая тема не предлагается, пока не начаты все темы курса.
- **Заметки:** все проекты, 100 %. Возможно, задумано, но тогда код ветки `reason === 'weak'` в SyllabusPage недостижим.

### C-03 · «С агентом»: после «Отметить пройденным» подтверждение исчезает, фокус падает на <body>
- **Серьёзность:** P3 (low) — занятие сохраняется, но пользователь не видит «Занятие засчитано: N/M · статус …»;
  клавиатурный фокус теряется (у кнопки нет преемника), экранный диктор ничего не объявляет.
- **Где:** src/features/tutor/TutorHubPage.tsx:88 (`<TutorPanel key={dailyKey}>`): после сохранения прогресс меняет
  подбор «Беседы дня» → новый `dailyKey` → панель и CompleteForm монтируются заново, `msg` теряется.
- **Тест:** tests/e2e/local/practice/tutor.spec.ts › «hub: «Отметить пройденным» keeps the confirmation and focus [BUG C-03]».
- **Шаги:** 1) пустой профиль, `/practice/tutor`; 2) «Отметить пройденным» → «Нормально 7/10» → «Отметить пройденным».
- **Ожидается:** строка `role=status` «Занятие засчитано: 7/10 · …» с фокусом (как на вкладке «С агентом» в теме).
- **Фактически:** строки нет, `document.activeElement === body`; тема «Беседы дня» сменилась. В истории запись есть.
- **Заметки:** все проекты, 100 %. На вкладке темы (`/topic/:id?tab=tutor`) всё работает — там ключ не меняется.

### C-04 · «Практика · С агентом» на ширине 360 px — горизонтальная прокрутка страницы
- **Серьёзность:** P2 (medium) — на популярных Android-экранах 360 px вся страница «ездит» по горизонтали на 16–22 px,
  карточки тем обрезаны справа (390 px и шире — в порядке).
- **Где:** src/features/tutor/TutorHubPage.tsx:116 (`<ul className="grid … sm:grid-cols-2">` «Темы для занятия»; та же
  разметка в :148 «Ситуации для сценок») + `linkCard` (:16). Трек `grid` = `minmax(auto, 1fr)`: min-content карточки
  (длинное слово «существительных» + LevelBadge + StatusBadge «Не начато» + шеврон) шире контейнера; `min-w-0` стоит только на
  внутреннем `<span>`, у `<li>`/ссылки его нет (лечится `grid-cols-[minmax(0,1fr)]` или `min-w-0` на `<li>`).
- **Тест:** tests/e2e/local/navigation/layout.spec.ts › «tutor hub: no horizontal page scroll @360px [BUG C-04]».
- **Шаги:** 1) пустой профиль; 2) ширина окна 360 px; 3) `/practice/tutor`, прокрутить к «Темы для занятия».
- **Ожидается:** `document.documentElement.scrollWidth === clientWidth`.
- **Фактически:** переполнение 16 px (Chromium) / 22 px (WebKit): `<li>` трёх карточек тем заканчиваются на x = 376–382.
- **Заметки:** desktop-chromium, mobile-chromium, mobile-webkit при 360 px; 100 %. Скриншот: `test-results/e2e-C/…tutor-hub…/test-failed-1.png` при снятии `test.fail`.
