## Грамматика

| Явление | Португалия | Бразилия |
|---|---|---|
| Длительное действие | **estar a + inf.**: *Estou a comer.* | estar + герундий: *Estou comendo.* |
| Место клитика | после глагола: *Chamo-me Ana. Diz-me.* | перед глаголом: *Me chamo Ana. Me diz.* |
| «Ты» | **tu** + 2 л.: *Tu falas* | você + 3 л.: *Você fala* |
| «Вы» вежливо | *o senhor / a senhora*, имя или пропуск местоимения: *O senhor deseja…? Quer um café?* | você |
| Артикль перед притяжательным | обязателен: ***o** meu carro* | часто опускается: *meu carro* |
| Местоимение-дополнение | *Vi-o. Conheço-a.* | *Vi ele. Conheço ela.* (разг.) |
| Обязанность | ***ter de** + inf.* | *ter que + inf.* |
| Направление | *Vou **ao** cinema. Cheguei **a** casa.* | *Vou **no** cinema. Cheguei **em** casa.* (разг.) |
| «Мы» | ***nós*** | часто *a gente* |
| Perfeito 1 л. мн. ч. (-ar) | ***falámos*** (прош.) ≠ *falamos* (наст.) | *falamos* в обоих значениях |
| Вежливая просьба | imperfeito: *Queria um café.* | *Eu queria / Me vê um café.* |
| Ответ «да» | повтор глагола: *— Tens fome? — **Tenho.*** | *— Sim.* |

## Произношение

| Черта | Португалия | Бразилия |
|---|---|---|
| Безударные гласные | редуцируются, почти исчезают: *telefone* [tɨlˈfɔn] | произносятся полно: [teleˈfoni] |
| **s** в конце слога | [ʃ] — «ш»: *mais, festa* | [s] (кроме Рио) |
| **de, te** | [dɨ], [tɨ] | [dʒi], [tʃi] |
| **r** в начале слова, **rr** | гортанное [ʁ] | [h] |
| **l** в конце слога | твёрдое [ɫ]: *Portugal* | [w]: «Portugau» |
| Ритм | быстрый, «съеденные» гласные | певучий, открытые гласные |

## Повседневные фразы

| Ситуация | Португалия | Бразилия |
|---|---|---|
| Ответ по телефону | *Está? / Estou?* | *Alô?* |
| Привет, как дела? | *Olá, tudo bem? / Como estás?* | *Oi, tudo bom? / Como vai?* |
| Счёт, пожалуйста | *A conta, se faz favor.* | *A conta, por favor.* |
| Ок, договорились | *Está bem. / Combinado.* | *Tá bom. / Beleza.* |
| Согласие, поддакивание | *Pois. / Pois é.* | *É. / Né?* |
