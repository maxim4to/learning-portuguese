# Предлоги и слияния

Слияния предлогов с артиклями и местоимениями, предлоги места и времени, глаголы с управлением и выбор между **por** и **para**.

## Слияния с артиклями

| Предлог | o | a | os | as | um | uma | uns | umas |
|---|---|---|---|---|---|---|---|---|
| **a** | ao | à | aos | às | a um | a uma | a uns | a umas |
| **de** | do | da | dos | das | dum / de um | duma / de uma | duns | dumas |
| **em** | no | na | nos | nas | num | numa | nuns | numas |
| **por** | pelo | pela | pelos | pelas | por um | por uma | por uns | por umas |

> С неопределённым артиклем в pt-PT нормально и слитно (*num café*, *duma vez*), и раздельно (*de um amigo*). С **a** слияния с *um* нет.

## Слияния с указательными и местоимениями

| | de | em | a |
|---|---|---|---|
| este / esta / isto | deste / desta / disto | neste / nesta / nisto | a este |
| esse / essa / isso | desse / dessa / disso | nesse / nessa / nisso | a esse |
| aquele / aquela / aquilo | daquele / daquela / daquilo | naquele / naquela / naquilo | **àquele / àquela / àquilo** |
| ele / ela / eles / elas | dele / dela / deles / delas | nele / nela / neles / nelas | a ele |
| aqui / aí / ali | daqui / daí / dali | — | — |
| outro / outra | doutro / doutra | noutro / noutra | a outro |

*O carro **dele*** (его машина) · ***Nisso** tens razão.* · *Vou **àquela** loja.*

## Место

| Предлог | Значение | Пример |
|---|---|---|
| **em** | в, на (где?) | *Estou **em** casa / **no** escritório / **na** praia.* |
| **a** | направление (кратко, ненадолго) | *Vou **ao** supermercado. Fui **a** Lisboa no sábado.* |
| **para** | направление (надолго, с целью остаться) | *Vou **para** casa. Mudei-me **para** o Porto.* |
| **de** | откуда | *Sou **de** Moscovo. Venho **do** trabalho.* |
| **por** | через, по | *Passei **pelo** centro. Vamos **pela** ponte.* |
| **até** | до (предела) | *Vou a pé **até** à estação.* (в pt-PT обычно **até ao / até à**) |
| **entre** | между | ***entre** a farmácia e o banco* |
| **sobre** / **em cima de** | на, над | *O livro está **em cima da** mesa.* |
| **debaixo de** / **por baixo de** | под | ***debaixo da** cama* |
| **ao lado de**, **perto de**, **longe de** | рядом, близко, далеко | *Moro **perto da** praia.* |
| **em frente a / de** | напротив | ***em frente ao** café* |
| **atrás de**, **dentro de**, **fora de** | за, внутри, снаружи | ***atrás da** porta* |

## Время

| Выражение | Значение | Пример |
|---|---|---|
| **às** + час | в (о времени) | ***às** três (horas), **à** uma, **ao** meio-dia* |
| **de** manhã / **à** tarde / **à** noite | утром / днём / вечером | *Trabalho **de** manhã e estudo **à** noite.* |
| **em** + месяц / год | в | ***em** janeiro, **em** 2024* |
| **a** + дата | число | *Nasci **a** 5 de maio.* (pt-PT) |
| **ao** fim de semana | по выходным | ***Ao** fim de semana vou à praia.* (pt-BR: *no fim de semana*) |
| **há** + период | … назад; уже … | *Cheguei **há** dois anos.* · *Moro cá **há** dois anos.* |
| **daqui a** + период | через | ***Daqui a** uma hora.* |
| **desde** | с (какого-то момента) | ***desde** segunda-feira, **desde** 2020* |
| **durante** | в течение | ***durante** as férias* |
| **por volta de** | около | ***por volta das** oito* |
| **até** | до | ***até** amanhã, **até às** seis* |
| **dentro de** | в пределах, через | ***dentro de** uma semana* |

## Транспорт и способ

- ***de** comboio / autocarro / carro / avião*, но ***a** pé*, ***a** cavalo*
- *pagar **com** cartão / **em** dinheiro* · *escrever **à** mão / **a** lápis*
- *falar **ao** telefone* (pt-PT) · *ver **na** televisão*

## Глаголы с предлогами

| + de | + em | + a | + com | + por |
|---|---|---|---|---|
| gostar **de** | pensar **em** | começar **a** | sonhar **com** | interessar-se **por** |
| precisar **de** | acreditar **em** | chegar **a** (pt-PT) | casar **com** | passar **por** |
| lembrar-se **de** | confiar **em** | ajudar **a** | contar **com** | optar **por** |
| esquecer-se **de** | reparar **em** | aprender **a** | preocupar-se **com** | esperar **por** |
| depender **de** | insistir **em** | voltar **a** (= снова) | concordar **com** | trocar **por** |
| acabar **de** (только что) | entrar **em** | habituar-se **a** | parecer-se **com** | |
| deixar **de** (перестать) | | assistir **a** (смотреть) | | |
| ter **de** (быть должным) | | | | |

> В pt-PT: *Cheguei **a** casa* (не *em casa*), *Entrei **no** carro*, *Vou **à** escola*.

## por или para?

| para | por |
|---|---|
| цель: *Estudo **para** passar no exame.* | причина: *Obrigado **pelo** presente.* |
| получатель: *Isto é **para** ti.* | путь, через: *Passámos **por** Coimbra.* |
| направление: *Vou **para** Faro.* | обмен, цена: *Comprei-o **por** dez euros.* |
| срок: *É **para** sexta-feira.* | приблизит. время: ***Pelo** Natal vou a casa.* |
| мнение: ***Para** mim, está ótimo.* | агент в пассиве: *Foi escrito **por** Saramago.* |
| | частота: *duas vezes **por** semana* |
